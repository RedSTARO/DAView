# DAView 界面设计：放映室

两端共用一套 [Material 3 Expressive](https://m3.material.io/) 主题。表现力集中在首页的续播区与详情的播放入口；筛选、表单和播放控制以易扫读和易操作为先。

## 采用的 M3 规则

- **角色，而不是固定颜色**：内容区用 `surface`，导航区用 `surfaceContainer`。主要操作用 `primary`，导航与筛选选中态用 `secondaryContainer`，少量特殊状态用 `tertiary`。内容颜色使用配对的 `on*` 角色；普通小字至少 4.5:1，对比度较低的边框不单独承担状态含义。
- **字号、形状与触控**：使用 Compose Material 原生字阶和圆角阶梯。标题、主操作、选中标签有选择地使用强调字阶；长正文与次要元数据仍用常规字阶。按实际面板宽度使用紧凑窗口 16 dp、其余 24 dp 的页面边距。目标触控区域以 48×48 dp 为基线，正文可换行，关键操作不依赖颜色、鼠标悬停或手势。
- **布局与动效**：紧凑手机用底部导航，空间充足时用导航轨；内容页使用适应窗口的单栏或列表—详情布局。台前操作用组件原生按压反馈，几何变化用 `spatial` 弹簧，透明度和颜色用不会回弹的 `effects` 弹簧。

## DAView 的设计选择（非 M3 强制规格）

- **首页**：已在观看的内容优先成为焦点，无续播时依次回退到「接下来」「最近添加」。宽面板用电影横幅：剧照贴满卡片尾侧，在纯色文案区外渐隐，状态栏和页面边缘不绘制封面。空间有限时，剧照改在文字上方；无法并排的短窗或无图时不留图片占位。继续播放用小号填充按钮，详情用描边按钮；「整部剧」能同排时直接显示，否则收入更多菜单。接入 WebDAV、媒体库与片单的其他行为保持不变。
- **媒体库、搜索、片单**：筛选、排序和视图切换都在内容集合外。窗口太短或键盘占用空间时可以用文字优先的列表行；状态与滚动锚点跟随条目而不是它的呈现形式。
- **详情**：顶部固定返回栏；封面、标题、观看状态和主播放按钮收在首卡，宽面板的剧照贴在卡片尾侧，窄面板用小图或纯文字。简介默认短预览；文件信息先给摘要，点开才显示可复制的路径、音轨和字幕。同季横卡点剧照播放（圆形播放键常驻居中），点标题进分集详情；纵向选集把播放、标题和更多操作放在同一行。当前集同时用色块和文字标记，不把观看、下载和外部播放等次级操作挂在卡片外。
- **弹层**：表单限制在可用面板中，标题和操作与滚动正文分开；编辑、手动匹配、合并和配置目录仍是各自独立的任务。
- **设置**：六个分类是设置页内的分页，不是应用主导航。窄面板用一条可横向滚动的图文标签，宽面板用前侧可独立滚动的分类列表与限宽表单并排；两者都用色块与强调字重标示当前分类。只在够宽且够高时加分类标题和说明，避免挤占窄窗首屏的表单空间。根据扣除系统边距、铰链和主导航后的空间以及字号切换排版，不另建表单，避免窗口或键盘变化时丢失草稿和焦点。
- **播放**：控件使用深色的配对颜色，即使应用本身为浅色。窄窗收纳辅助操作，保留播放和返回等关键操作；Android 原生播放控件和 Windows 独立浮窗沿用原来的集成方式。系统禁用动画时，折叠过渡直接显示最终位置。
