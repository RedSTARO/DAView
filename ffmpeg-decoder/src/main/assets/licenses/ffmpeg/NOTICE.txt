FFmpeg in DAView for Android
============================

DAView plays DTS, Dolby TrueHD and AC-3 / E-AC-3 audio with FFmpeg's decoders
when the phone cannot decode it itself. FFmpeg is in these libraries, inside
the APK under lib/<abi>/:

  libavcodec.so  libavutil.so  libswresample.so

Version: FFmpeg 6.1.6, unmodified - git tag n6.1.6, commit
f1e3a2bf7a2f2cde936d1ed97f09a26853d20125.

Licence: GNU Lesser General Public License, version 2.1 or later. The full
text is COPYING.LGPLv2.1 next to this file. FFmpeg was configured without
--enable-gpl, --enable-nonfree and --enable-version3, so no GPL or non-free
part of it is included. A few of the source files compiled in carry
permissive licences of their own; their notices are at the end of this file.

Source code of exactly this version:

  https://github.com/FFmpeg/FFmpeg/tree/n6.1.6
  https://ffmpeg.org/releases/ffmpeg-6.1.6.tar.xz
  git://source.ffmpeg.org/ffmpeg.git (tag n6.1.6)

How the libraries were built: by scripts/build-ffmpeg-decoder.sh in
https://github.com/RedSTARO/DAView, with Android NDK r27d (27.3.13750724) for
API level 26. FFmpeg's configure ran with the NDK's toolchain directory on
PATH, from an empty build directory holding a link named "src" to the source.
These are its configure lines as libavcodec.so records them (what
avcodec_configuration() returns), one per ABI:

armeabi-v7a:
--target-os=android --arch=arm --cpu=armv7-a --cross-prefix=armv7a-linux-androideabi26- --nm=llvm-nm --ar=llvm-ar --ranlib=llvm-ranlib --strip=llvm-strip --enable-shared --disable-static --disable-programs --disable-doc --disable-debug --disable-everything --disable-avdevice --disable-avformat --disable-swscale --disable-postproc --disable-avfilter --disable-network --disable-symver --disable-autodetect --disable-iconv --enable-swresample --enable-decoder='ac3,eac3,dca,truehd,mlp' --extra-cflags='-D__BIONIC_NO_PAGE_SIZE_MACRO -march=armv7-a -mfloat-abi=softfp' --extra-ldflags='-Wl,-z,max-page-size=16384 -Wl,--build-id=sha1 -Wl,--no-rosegment -Wl,--fix-cortex-a8'

arm64-v8a:
--target-os=android --arch=aarch64 --cpu=armv8-a --cross-prefix=aarch64-linux-android26- --nm=llvm-nm --ar=llvm-ar --ranlib=llvm-ranlib --strip=llvm-strip --enable-shared --disable-static --disable-programs --disable-doc --disable-debug --disable-everything --disable-avdevice --disable-avformat --disable-swscale --disable-postproc --disable-avfilter --disable-network --disable-symver --disable-autodetect --disable-iconv --enable-swresample --enable-decoder='ac3,eac3,dca,truehd,mlp' --extra-cflags=-D__BIONIC_NO_PAGE_SIZE_MACRO --extra-ldflags='-Wl,-z,max-page-size=16384 -Wl,--build-id=sha1 -Wl,--no-rosegment'

x86:
--target-os=android --arch=x86 --cpu=i686 --cross-prefix=i686-linux-android26- --nm=llvm-nm --ar=llvm-ar --ranlib=llvm-ranlib --strip=llvm-strip --enable-shared --disable-static --disable-programs --disable-doc --disable-debug --disable-everything --disable-avdevice --disable-avformat --disable-swscale --disable-postproc --disable-avfilter --disable-network --disable-symver --disable-autodetect --disable-iconv --enable-swresample --enable-decoder='ac3,eac3,dca,truehd,mlp' --extra-cflags=-D__BIONIC_NO_PAGE_SIZE_MACRO --extra-ldflags='-Wl,-z,max-page-size=16384 -Wl,--build-id=sha1 -Wl,--no-rosegment' --disable-asm

x86_64:
--target-os=android --arch=x86_64 --cpu=x86-64 --cross-prefix=x86_64-linux-android26- --nm=llvm-nm --ar=llvm-ar --ranlib=llvm-ranlib --strip=llvm-strip --enable-shared --disable-static --disable-programs --disable-doc --disable-debug --disable-everything --disable-avdevice --disable-avformat --disable-swscale --disable-postproc --disable-avfilter --disable-network --disable-symver --disable-autodetect --disable-iconv --enable-swresample --enable-decoder='ac3,eac3,dca,truehd,mlp' --extra-cflags=-D__BIONIC_NO_PAGE_SIZE_MACRO --extra-ldflags='-Wl,-z,max-page-size=16384 -Wl,--build-id=sha1 -Wl,--no-rosegment' --disable-asm

The libraries are linked dynamically. libffmpegJNI.so, the JNI wrapper from
AndroidX Media (Apache License 2.0; its source is in the DAView repository
under ffmpeg-decoder/), loads them by file name. To run DAView with a
different build of FFmpeg, build these three libraries from the source above,
or from a modified version of it, put them into lib/<abi>/ of the APK in place
of the ones there, and sign the APK again.
